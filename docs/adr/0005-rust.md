# ADR-0005 — The tool is written in Rust

**Status:** accepted (2026-11-22)

## Context

The owner prefers Rust and doesn't want to maintain a Python environment. The exploration used
throwaway Python scripts.

## Decision

The tool is written in Rust. The darktable integration is a thin Lua layer, because darktable
only offers Lua. Python is used only for throwaway experiments, which are not part of the tool.

## Consequences

- A single binary to install on the owner's machine.
- The experiments' findings are carried over as rules, not as code.
